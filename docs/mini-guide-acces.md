# Mini guide d'accès — où il vit

Le mini guide d'accès des équipes clientes est **[`mcp_server/README.md`](../mcp_server/README.md)**.

Il vit à côté du code qu'il documente, et pour la raison que le brief énonce lui-même : le
livrable est « le serveur MCP (`mcp_server/`) exposant le catalogue complet **ainsi qu'un mini
guide d'accès** ». Les deux dans le même dossier, donc, pour qu'aucun des deux ne bouge sans
l'autre.

Ce fichier n'est qu'un panneau indicateur, pour qui parcourt `docs/`.
